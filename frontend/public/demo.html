[0:00 - 0:50] 1. The Challenge in Modern Software:
[Screen Action: Start on Login page → Click 'Judge Fast Pass' → Show Dashboard alert counters]
"Hello everyone, and respected judges! Today, modern applications are built using hundreds of open-source packages and dependencies across npm, Python, Go, and GitHub workflows. While open-source libraries help us build products faster, managing their security has become extremely complex. In large codebases, applications often contain multiple levels of nested dependencies. The real challenge for engineering teams is knowing: Which vulnerabilities are actually reachable and active in production code, and which ones are never called? Without this reachability context, developers can spend weeks investigating alerts or risk breaking live backend APIs during package upgrades. That is why modern software security requires a deeper, code-aware approach."

[0:50 - 1:35] 2. Introducing SupplyGraph:
[Screen Action: Smoothly scroll down ASPM dashboard → Highlight multi-ecosystem support: npm, PyPI, Go, Actions]
"To address this challenge, we created SupplyGraph. SupplyGraph is an Application Security Posture Management platform designed to give developers complete visibility into their software supply chain. Instead of treating dependencies as flat isolated lists, SupplyGraph analyzes your project's call paths and builds an interactive visual attack graph. It connects your code from user-facing entry points all the way down to deeply nested libraries. It clearly verifies whether an execution path actually reaches a vulnerable component. When an issue is identified, SupplyGraph provides safe, line-by-line code patches that preserve application functionality, while testing untrusted packages inside an isolated sandbox."
