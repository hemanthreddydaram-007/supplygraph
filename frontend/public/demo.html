[0:00 - 0:55] 1. The Challenge in Modern Software:
"Hello everyone, and respected judges! Today, modern applications are built using hundreds of open-source packages and dependencies across npm, Python, Go, and GitHub workflows. The real challenge for engineering teams is knowing: Which vulnerabilities are actually reachable and active in production code, and which ones are never called? Without this reachability context, developers can spend weeks investigating alerts or risk breaking live backend APIs during package upgrades. "To address this challenge, we created SupplyGraph. It connects your code from user-facing entry points all the way down to deeply nested libraries. It clearly verifies whether an execution path actually reaches a vulnerable component. When an issue is identified, SupplyGraph provides safe, line-by-line code patches that preserve application functionality, while testing untrusted packages inside an isolated sandbox."
